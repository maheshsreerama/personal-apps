# Personal Apps

Small personal apps.

## Apps

- **[Learn Java — Concepts & Examples](java-learning/)** — a complete offline Java course as an Android app: 14 parts / 53 chapters covering basics, OOP, strings, collections, generics, multithreading, Java 8+ streams, I/O and more — every concept with a runnable example **and its output**, plus interview programs and a tricky-output quiz. Download the APK from the [Releases page](../../releases) (tags `java-v*`), or read the markdown directly in [`java-learning/`](java-learning/README.md).
- **[LLD Interview Notes](low-level-design/)** — complete Low-Level Design curriculum (Java edition) as an offline Android app: OOP foundations, SOLID, design patterns, concurrency, machine coding, and 13 real interview case studies with Mermaid diagrams. Download the APK from the [Releases page](../../releases/latest) (tags `lld-v*`), or read the markdown directly in [`low-level-design/`](low-level-design/README.md).
- **[Four Cars](four-cars/)** — the two-car arcade classic, doubled: four roads, four cars, two lanes each. Tap a quarter of the screen to switch that car's lane, collect every circle, dodge every square — miss one circle and the run is over. Native `SurfaceView` render thread, vsync-paced, no allocations on the hot path. Download the APK from the [Releases page](../../releases) (tags `cars-v*`).
- **[Interview Prep 84](interview-prep/)** — an 84-day senior-backend interview plan (DSA, Java internals, machine coding, HLD, behavioural) and the offline Android app that tracks it: the day's timed blocks, a spaced-repetition problem log, an 84-day grid, and mock scoring against per-round rubrics. Download the APK from the [Releases page](../../releases) (tags `prep-v*`), or read the plan in [`PLAN.md`](interview-prep/PLAN.md).
- **[Love & War](couple-game.html)** — couples game night: 5 two-player mini-games for one shared tablet. Download the HTML file and open it in any browser (works offline).
