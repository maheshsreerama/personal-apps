**Java Ace** — an offline Android app that teaches every example from your HungryCoders Java course, plus the interview essentials beyond it.

This is a preview build: the app and all features work, and more lessons are being added. Each lesson has a concept deep dive, hand-drawn diagrams, your original code with its real output, traps and errata, tips, interview Q&A and a quiz.

**Install:** download `JavaAce-*.apk` below on your Android phone (Android 8.0+), open it and allow "install unknown apps" when asked. Updates install over the previous version and keep your progress.
