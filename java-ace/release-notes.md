**Java Ace 1.0.0** — an offline Android app that teaches every example from your HungryCoders Java course, plus the interview essentials beyond it.

**What's inside**
- **185 lessons:** 142 teach the course material, and all 140 example programs plus `pom.xml` and `AppTest.java` are covered. The other 43 are interview essentials the course doesn't cover.
- **1,858 interview questions** with model answers, marked Basic, Intermediate or Advanced.
- **1,301 quiz questions**, each with an explanation.
- **472 hand-drawn diagrams**, and a mind map for every module plus one for the whole course.
- Every example shows its **real output** (recorded on JDK 21). Tap to reveal it after you predict it. Outputs that change between runs are flagged.
- **Errata:** the lessons point out wrong comments and bugs in the original examples and show how to fix them.

**Course (Track A):** OOP · Core Language · Collections · Generics · Java 8 Lambdas & Streams · Multithreading · Executors, Callable & Future · IO & Serialization · NIO · Design Patterns

**Interview essentials (Track B):** Java Fundamentals · JVM Internals & Memory · Advanced Concurrency · Collections Internals · Modern Java (9–21) · Coding Interview Drills

**Each lesson has:** in one line · mental model · concept deep dive · diagrams · your original code with its output · line-by-line walkthrough · traps · tips & memory tricks · interview Q&A · quiz · takeaways.

**Practice:** quizzes by module or the whole course, spaced-repetition flashcards, timed mock interviews with a weak-areas report, cheat sheets, search, bookmarks and progress tracking.

**Sketchpad:** a built-in Excalidraw board. Open any lesson diagram as editable shapes, or draw it from memory to test yourself.

Fully offline, no account, dark mode.

**Install:** download `JavaAce-1.0.0.apk` below on your Android phone (Android 8.0+), open it and allow "install unknown apps" when asked. It installs over the 0.1.0 preview and keeps your progress.
